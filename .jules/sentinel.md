## 2024-07-02 - [CRITICAL] Unauthenticated Admin/Supervision Endpoint
**Vulnerability:** The `/supervise/` WebSocket endpoint used for observing and interacting with sessions (including administrative actions like cancellation and resolving approvals) was completely unauthenticated, allowing any user who guesses a session ID to access admin functionality.
**Learning:** WebSocket endpoints with administrative privileges in the system require dedicated authentication mechanisms, especially since browser WebSockets can't easily send HTTP headers. The `session_id` was relatively short and guessable. The endpoint lacked an explicit check for an authentication token despite being intended for administrative supervision.
**Prevention:** Always require authentication on admin endpoints. For WebSockets, this can be done by parsing a token from the initial connection message (e.g., `subscribe` command) and securely comparing it to an expected value (like an environment variable) using `secrets.compare_digest` to prevent timing attacks.
